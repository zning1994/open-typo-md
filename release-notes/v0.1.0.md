The first release of Mosu — an open-source WYSIWYG Markdown editor. No split
pane, no preview pane: what you type is what you see.

Markdown markers appear only when the cursor enters an element, and fold back
when it leaves. The buffer holds exactly the bytes on disk, so opening a file and
saving it leaves it byte-identical.

## What's in it

- **Live preview for all of CommonMark**, plus GFM: tables that lay out as
  tables, task lists you can click, strikethrough, autolinks, footnotes
- **Math** (KaTeX) and **Mermaid diagrams**, both lazy-loaded
- **Tabs, multiple windows and session restore**; per-tab undo and dirty state
- **Table editing** — Tab between cells, insert/delete rows and columns, set
  alignment, reflow. All plain text transformations, so undo stays correct
- **Export to HTML** (one self-contained file: styles, images, math fonts and
  diagram SVGs inlined) and **to PDF**
- **Copy as rich text**, **paste HTML as Markdown**
- **Six themes** including high contrast, plus focus mode and typewriter mode
- **Outline panel, command palette, file tree, find and replace**
- **Interface in Simplified Chinese, English or Japanese**, switchable without a
  restart
- **Rebindable shortcuts** — press the combination you want; conflicts are flagged
- Crash recovery, file watching, atomic writes, external-modification detection

## Installing

**macOS** — signed with a Developer ID certificate and notarised by Apple.
Double-click and it opens: no Gatekeeper prompt, no `xattr` incantation. Take the
`arm64` build on Apple Silicon, `x64` on Intel.

**Windows** — **not signed yet.** SmartScreen will say "Windows protected your
PC"; click "More info" → "Run anyway". This is deliberate rather than pending:
unlike macOS, a signature alone does not remove the warning — an ordinary
certificate has to accumulate install reputation first, and the kind that works
immediately is expensive and needs a cloud signing service.

**Linux** — make the AppImage executable first:

```bash
chmod +x Mosu-*.AppImage && ./Mosu-*.AppImage
```

## Not there yet

The plugin system, cross-file search, user theme directories, Pandoc-based export
(DOCX / ePub / LaTeX), drag-to-resize table columns, and auto-update. Block-level
HTML rendering (`<div>…</div>`) is a deliberate no rather than a scheduling
matter — the reasoning is in the README.

Every rough edge is written down at the end of each milestone in the roadmap,
under "what actually differed from the plan". Nothing is swept under the rug.
